## What it is

OrielHub is a Mac app for working with the coding agents you already use,
such as Claude Code, Codex, Gemini CLI and Grok. Write a task, hand it to an
agent, and follow the work from one window and the menu bar.

## What it solves

- **Agents scattered across terminals.** Every task, with every agent, sits on
  one board.
- **Questions you never saw.** Everything an agent is waiting on you for, in
  any task, is in one list.
- **Work that stalls without telling you.** OrielHub lets you know when an
  agent has gone quiet.
- **Not knowing what you spend.** Usage for each agent, and for each task.

## What gets easier

- **Nothing to set up.** OrielHub finds the agents on your Mac by itself.
- **One click away.** Check on your agents and answer them from the menu bar.
- **Find anything again.** Search across tasks and conversations.
- **Leave it running.** Your Mac stays awake while agents work.
- **Always current.** OrielHub updates itself.
